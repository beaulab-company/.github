# 뷰랩 조직 공통 안내

조직 공개 소개와 기본 협업 양식을 관리합니다. 서비스 소스·계정·서버 비밀값·내부 운영 문서는 포함하지 않습니다.

- `profile/README.md`: 공개 조직 소개
- `CONTRIBUTING.md`: 공통 작업 원칙
- `pull_request_template.md`: 변경 내용·검증·API/DB 영향·배포 주의사항
- `ISSUE_TEMPLATE/`: 오류 신고와 기능 작업 양식

각 저장소에 같은 종류의 양식이 있으면 해당 저장소의 양식이 우선합니다. 공통 양식을 적용하려고 기존 양식을 삭제하지 않습니다.
